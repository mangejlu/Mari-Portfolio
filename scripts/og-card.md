# Regenerating public/og.png

`og.png` is the social preview card. LinkedIn, Slack, iMessage and Twitter all
read it from `<meta property="og:image">`; without it they render a blank grey
box, and LinkedIn's Featured section refuses the link outright.

It is generated by hand rather than by a script, because nothing on this
machine outside a browser can rasterise the site's own fonts:

- Astro downloads the faces as **woff2**, which neither fontconfig nor Pango
  reads.
- sharp's `fontfile` option is a no-op on macOS.
- fontconfig ignores every custom `<dir>` it was pointed at, including one
  inside the project, and silently falls back to Helvetica. A card in the wrong
  typeface looks identical in file size, so this failure is easy to ship.

So the browser draws it. With `npm run dev` running, open the site and paste
this into the devtools console. It renders the card in the fonts the page has
already loaded and downloads the result; move it to `public/og.png`.

```js
const cs = getComputedStyle(document.documentElement);
const disp = cs.getPropertyValue('--font-display').trim();
const body = cs.getPropertyValue('--font-body').trim();
await document.fonts.load(`italic 500 58px ${disp}`);
await document.fonts.load(`400 23px ${body}`);
await document.fonts.ready;

const W = 1200, H = 630, PAD = 88;
const c = document.createElement('canvas');
c.width = W; c.height = H;
const x = c.getContext('2d');

x.fillStyle = '#fff8ef';
x.fillRect(0, 0, W, H);
const blobs = [
  [1010, 130, 250, '191,226,140'],
  [1120, 470, 230, '245,175,201'],
  [830, 610, 210, '245,180,140'],
  [120, 590, 190, '255,242,168'],
];
x.save();
x.filter = 'blur(70px)';
x.globalAlpha = 0.72;
for (const [cx, cy, r, rgb] of blobs) {
  const g = x.createRadialGradient(cx, cy, 0, cx, cy, r);
  g.addColorStop(0, `rgba(${rgb},1)`);
  g.addColorStop(1, `rgba(${rgb},0)`);
  x.fillStyle = g;
  x.beginPath();
  x.arc(cx, cy, r, 0, Math.PI * 2);
  x.fill();
}
x.restore();

x.textBaseline = 'alphabetic';
x.fillStyle = '#3b332f';
x.font = `italic 500 30px ${disp}`;
x.fillText('mari.', PAD, 116);

x.font = `italic 500 58px ${disp}`;
let y = 288;
for (const l of ['hi, i’m mari.', 'i design solutions that', 'make lives easier.']) {
  x.fillText(l, PAD, y); y += 76;
}

x.fillStyle = 'rgba(59,51,47,0.66)';
x.font = `400 23px ${body}`;
const url = 'design-mari.vercel.app';
x.fillText('product designer & front-end developer', PAD, 548);
x.fillText(url, W - PAD - x.measureText(url).width, 548);

const a = document.createElement('a');
a.download = 'og.png';
a.href = c.toDataURL('image/png');
a.click();
```

Then squash it: `npx sharp-cli -i public/og.png -o public/og.png png`, or any
PNG optimiser. It lands around 100 kB.

**Check the type before shipping.** If the headline is in a sans, the fonts
had not loaded when the snippet ran. Reload, wait for the page to settle, and
run it again.
